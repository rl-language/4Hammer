# Model characteristics — batch17.C2a

Authority: supplied [Modifiers appendix02.02.01](11th-edition-supplied-appendix.md), [Multiple Toughness Characteristics appendix05.02.01](https://wahapedia.ru/wh40k11ed/the-rules/rules-appendix/), core Leadership/Battle-shock p.9, attack/save groups pp.18–19, movement p.33 and objectives p.52. Retrieved appendix05.02.01 requires the highest battlefield T in an unattached unit; attached units first use their battlefield bodyguards. Bodyguard provenance remains17.G.

Each Model stores a sparse, checked list of up to16 `CharacteristicModifier` records, each with an enum characteristic and ordinary bounded signed operation metadata. Queries filter by characteristic, then use the shared replacement/multiplication/addition/division/subtraction order, final upward rounding and characteristic limits. This avoids a separate16-slot list for every possible characteristic. All persistent numbers remain standard bounded fields; there are no custom lifecycle hooks or observation encodings.

Actual consumers now read effective M, T, Sv, InSv, Ld and OC. Movement applies M modifiers to the fixed or already determined random base, before Advance extras; fixed Scouts/Surge distances remain separate. Both independent movement budgets and the older staged path kernel use the effective value. Attack configuration and Crushing Impact read effective Toughness and assert that their bounded snapshots can represent it, rather than silently clamping the value. The unit maximum no longer shadows its accumulator and excludes offboard models; retained Fight on Death models remain constituents on the battlefield until removal. Save groups split by modified Sv/InSv and retain the ordinary wound/character rules. Leadership chooses the best effective bearer threshold. Objective control and generic action eligibility use effective bearer OC; Battle-shock's '-' still contributes zero regardless of bonuses.

Legacy profiles use values above6 for absent InSv. That absence is unmodifiable; arithmetic cannot manufacture an invulnerable permission. Valid InSv and Sv retain their2+ floor. A replacement with zero locks further arithmetic and skips minima. Saved live/archive model metadata rejects invalid enums/amounts and nonpositive divisors before effective queries run.

This batch installs arithmetic infrastructure and explicit regression fixtures. It does not invent faction grants, automatically distribute a bearer effect to a unit, evaluate live auras, or expire source effects. Those consumers must install/remove the affected records with their printed source scope and duration in the later source-instance batches. Attached bodyguard selection, weapon characteristics, named selectors and arbitrary special profile metadata remain pending. Initial target configuration now snapshots effective T; refreshing it for each newly gathered group after intervening modifiers/casualties is a mandatory17.C2b follow-up, together with complete effective attack grouping. No current datasheet is certified.

State/observation schemas are19, action14 and next-state20. Native/header/C++ artifacts must match. Grid coordinates and action domains are unchanged. ROADMAP.md retains the remaining17.C2b–C2c work.
