# Orks army and detachment configuration — batch 17.B

The [Orks faction source](https://wahapedia.ru/wh40k11ed/factions/orks/) and the user's scope establish independent army identity, up to three distinct detachments per player, no points or detachment-price accounting, and continued CP accounting. This batch supplies configuration and shared CP eligibility infrastructure; it does not implement detachment effects, enhancements, their actions or new datasheets.

## Configuration and action flow

`ArmyFaction` identifies the actual army independently of the preserved `Faction` legacy roster enum. The Chaos and Morgrim factories incorrectly returned the Tyranid roster identifier; their return values now identify their own rosters. Existing faction-specific dispatch consequently uses the intended legacy branch. Those legacy rules/data are not certified as current Orks rules; replacing them remains 17.F–H.

Each player owns an `ArmyConfiguration` with a checked three-element detachment vector. All 15 ordinary Orks packages are represented; Boarding Actions variants are excluded. `none`, duplicates, invalid enum values, non-Orks picks and a fourth pick are rejected. Zero, one or two choices may finish explicitly; the third automatically finishes. Selections are independent between players. War Horde uses one slot, without its printed DP cost. `select_orks_detachments` exposes one enum selector and a finish action through the existing editor action discovery.

Public roster selection explicitly configures point-free reserves for either player. Only the points-based reserve cap is bypassed: owner, repeated selection, Fortification, setup, arrival, capacity and offboard rules remain applicable. Point-free carriers do not require passenger prices. Default standalone Board fixtures retain `points_required`, preserving their explicit cost/cap assertions. No replacement unit-count percentage or pricing system is introduced (core p.68; user direction).

## Shared CP infrastructure

The [40-card inventory](orks-stratagem-costs.tsv) provides enum entries, printed base costs and selected-detachment gates. Infested War Zone costs 2CP; the other 39 cost 1CP. An explicit final cost supports discounts to zero and the Hulking Brutes +1CP option. Negative costs and increases greater than +1CP are rejected before expenditure (supplied appendix02.02.01 Modifiers). Zero-cost use still consumes the phase and target limits. CP and use records remain independent between players.

Breakin' Heads alone waives the common shocked-target restriction. Infested War Zone and Flyin' Headbutt accept real destroyed units, including retained destroyed models and archived casualties, while rejecting living units and arbitrary empty placeholders. These policies retain affordability, friendly ownership and per-player target/use checks (core p.54, destruction p.87; named Orks cards). The destroyed-unit policy does not also waive Battle-shock. Full printed timing, keyword, triggering-event and effect conditions belong to the later card actions: calling a common CP helper is not proof that an entire card is legal.
